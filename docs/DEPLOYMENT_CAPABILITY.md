# 钢珠检测部署能力分析

> 帧率优化 + 部署方式 + 能力边界。基于钢珠模型（yolo26n，mAP50 0.93）实测。

## 一、实测帧率基准（NVIDIA GPU，8GB）

| 部署方案 | 帧率 | 延迟/帧 | 说明 |
|---|---|---|---|
| **PyTorch GPU** | **86-95 FPS** | 11ms | 当前最佳，已超 60fps 目标 |
| ONNX CPU | 45-47 FPS | 21ms | 部署可用，无 GPU 时可用 |
| ONNX GPU | 待环境 | — | 需完整 CUDA 库环境 |

**结论**：PyTorch GPU 已实现稳定 60fps+ 目标（95 FPS），ONNX CPU 45fps 对多数场景够用。

## 二、部署方式对比

### 1. PC 端 GPU（本机，NVIDIA GPU）
- **PyTorch**：95 FPS，开发验证最佳
- **ONNX + CUDA**：预计 100+ FPS（需 CUDA 环境）
- **TensorRT**：预计 150+ FPS（NVIDIA 专用加速）
- 适合：原型开发、高精度实时检测

### 2. PC 端 CPU（无 GPU）
- **ONNX CPU**：45 FPS
- 适合：无 GPU 环境、批量离线处理

### 3. 嵌入式（K230 / Jetson Nano）
- **K230（RISC-V NPU）**：预计 30-60 FPS（K230 支持 YOLO 量化部署）
- **Jetson Nano**：TensorRT 加速，预计 60+ FPS
- 适合：边缘/机器人车载场景（低功耗边缘部署）

### 4. Web 交互（Gradio）
- 实时视频流：浏览器端 30 FPS（受网络/前端限制）
- 适合：交互演示、作品集展示

## 三、帧率优化路径

### 已达标的（PyTorch GPU）
```
预处理(letterbox) → 推理(8ms) → 后处理(NMS)
端到端 11ms → 95 FPS
```

### 进一步优化（如需更高帧率）

| 手段 | 原理 | 预计效果 |
|---|---|---|
| **TensorRT** | NVIDIA 引擎优化 | 150+ FPS |
| **ONNX GPU** | CUDA 加速 | 100+ FPS |
| **降低输入分辨率** | 640→512 | 更快但损失小目标精度 |
| **模型蒸馏** | 大模型→小模型 | 更快但需训练 |
| **批处理优化** | 多帧并行 | 吞吐提升 |

### 优化权衡
```
更快（降分辨率/小模型） → 损失精度
更准（高分辨率/大模型） → 降低帧率
需按场景权衡（实时应用要速度，检测任务要精度）
```

## 四、能力边界总结

| 场景 | 最佳方案 | 帧率 | 精度 |
|---|---|---|---|
| 实时控制（实时）| PyTorch/TensorRT | 60-150 FPS | 高 |
| 边缘部署（车载）| K230 量化 | 30-60 FPS | 中高 |
| 批量处理 | ONNX CPU | 45 FPS | 高 |
| 交互演示 | Gradio Web | 30 FPS | 高 |

## 五、关键结论

1. **60fps 目标已达成**（PyTorch GPU 95 FPS）
2. **部署格式**：ONNX 已验证可用（跨平台），GPU 加速是可选优化
3. **嵌入式**：K230/Jetson 是实时场景的下一步（低功耗实时）
4. **优化方向**：需要更高帧率时用 TensorRT/降分辨率（权衡精度）
5. **能力成熟**：钢珠检测的"训练→评估→部署→实时"闭环完整
