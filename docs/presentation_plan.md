### 第 7 页：改进一 — 大输入 + 强增强

**讲什么**：

三大修改 → 精确归因：

| 修改项 | Baseline | Improved | 效果 | 贡献度 |
|-------|:-------:|:--------:|:----:|:-----:|
| 模型升级 | YOLOv8n (3.2M) | YOLOv8s (11.2M) | 3.5×参数量 | ★★★ 主要 |
| 输入增大 | 640px | 800px | 小目标像素+25% | ★★☆ 重要 |
| 增强策略 | 默认(8种) | +MixUp/CopyPaste/Erasing/旋转 | 泛化提升 | ★☆☆ 辅助 |

**数学公式（可选）**：
- 15px 目标在 640px 下 → 4.8px（损失 89%）
- 15px 目标在 800px 下 → 6.0px（损失 60%）
- 800px 比 640px 多保留 **25%** 的小目标信息

**结果**：mAP@0.5 = 0.4258（+43.0%），小目标提升 **+96.7%**

**配图**：
- 训练曲线（loss 下降 + mAP 上升）
- baseline vs improved 检测对比图（标注框数量差异明显）

### 第 8 页：改进二 — SAHI 切片推理

**讲什么**：
- SAHI 是什么：大图切小块，每块独立推理再合并
- 为什么有效：切片保留了原始分辨率，15px 目标在切片中仍是 15px
- 参数：640×640 切片，20% 重叠，NMS 融合

**核心对比**：
```
传统方法：2000×1500 → resize 800 → 检测 → 15px变成6px
SAHI方法：2000×1500 → 切片→ 640×640 → 检测 → 15px依旧是15px ✓
```

**结果**：mAP@0.5 = 0.4523（+6.2%，零训练成本）

**SAHI 最适合的类别**：bicycle (+44.9%), pedestrian (+16.3%), people (+10.6%)

**SAHI 不擅长的类别**：awning-tricycle (-11.7%) —— 极稀疏类别丢失全局上下文

**配图**：
- SAHI 切片示意图
- 标准检测 vs SAHI 检测对比图（小目标明显增多）

**关键金句**：*"SAHI 用计算量换精度，但训练成本为零——这是性价比最高的提升手段"*

### 第 9 页：改进三 — 置信度阈值网格搜索

**讲什么**：
- 洞察：SAHI 将单个目标的置信度分散到多个切片中，标准阈值过滤掉了正确检测
- 方法：conf=0.05 收集所有预测 → 网格搜索 [0.05, 0.10, ..., 0.40]
- 结果：最优 conf=0.05

**关键数据**（推荐用折线图展示）：

```
conf=0.05 → mAP 0.4903  ◄ 最优（显著高于默认）
conf=0.10 → mAP 0.4826
conf=0.15 → mAP 0.4733
conf=0.20 → mAP 0.4635
conf=0.25 → mAP 0.4523  ◄ 默认
conf=0.30 → mAP 0.4389
conf=0.35 → mAP 0.4226
conf=0.40 → mAP 0.4021
```

**配图**：conf-mAP 折线图（x 轴 置信度，y 轴 mAP@0.5），标注 conf=0.05 和 conf=0.25 两个关键点

**关键金句**：*"这个发现反直觉但合理——SAHI 改变了置信度的分布，最优阈值因此发生了根本性偏移"*

### 第 11 页：架构探索 — P2 + CBAM

**讲什么**：
- P2 检测头：160×160 特征图，检测点数 8,400 → 34,000，最小可检测 <4px
- CBAM 注意力：3 个 CBAM 模块插入 backbone，强化有用通道和空间位置
- 工程难点：Ultralytics 自定义模块注册、懒初始化、兼容权重加载

**P2+CBAM 模型 vs 标准模型**：

| 指标 | YOLOv8s | P2+CBAM |
|:---:|:-------:|:-------:|
| 参数量 | 11.2M | 14.5M |
| 计算量 | 28.6 GFLOPs | 47.6 GFLOPs |
| 检测点数 | 8,400 | 34,000 |
| 最小检测目标 | ~16px | <4px |

**当前状态**（41 epoch，训练中）：
- mAP@0.5 = 0.2911（还在上升）
- 受限于 8GB VRAM，batch=4, imgsz=640（从 800 降级）
- 预计 80+ epoch 可达 0.35+

**配图**：P2 检测头架构图 + epoch-mAP 上升曲线

**关键金句**：*"P2+CBAM 是架构层面的真改进，但需要更多算力支撑收敛"*

### 第 14 页：关键经验总结

**讲什么**（每点 30 秒，共 3 分钟）：

1. **小目标检测=信息瓶颈问题**：输入尺寸决定了上限，模型结构决定逼近程度
2. **渐进式实验的高效性**：一次只改一个变量，每个改进可量化归因。避免"黑箱式改进"
3. **推理优化性价比最高**：SAHI + 阈值搜索，零训练成本提升 23.5%（从 0.4258 到 0.4903）
4. **直觉不一定对**：SAHI 下最优阈值是 0.05 而非 0.25，用数据说话
5. **集成不是银弹**：高质量模型才值得集成，否则适得其反
6. **资源约束不可忽视**：P2+CBAM 理论好但实践受限于显存，工程取舍很重要

### 应付提问的储备

1. **"为什么不用 YOLOv11？"** → YOLOv11 提出时项目已到后期，时间不够重训，但 wind-turbine 应用已配置好了 YOLOv11 方案
2. **"SAHI 这么慢怎么落地？"** → 精度优先场景可用（离线分析），实时场景用单模型（Improved 0.4258@0.05s/img）
3. **"P2+CBAM 为什么不继续训？"** → 受限于 8GB VRAM 降级了输入尺寸，需更多 epoch 收敛，发布论文前需补完
4. **"bicycle 提升 311% 是不是过拟合？"** → bicycle 基数极低 (0.062)，0.062→0.255 绝对值提升 0.193，符合正常范围
5. **"既然 SAHI 这么好，为什么不从头就做？"** → 渐进式实验的目的是验证每一步独立贡献，SAHI 是推理优化与训练无关
