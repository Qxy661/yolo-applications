# 技术总结（展示态 · 精炼）

> YOLO 小目标检测的完整应用闭环。本页是工程层面的精炼总结，
> 详细原理见 [tutorial/](tutorial/00-README.md) 知识体系。

## 闭环流程

```
数据准备 → 训练微调 → 评估优化 → 部署上线
```

## 一、数据准备

| 数据集 | 说明 | 处理 |
|---|---|---|
| VisDrone | 无人机俯拍，10 类，2000×1500 | 已转 YOLO 格式 |
| SteelBall | 电赛 H题，单类钢珠，2026-07 采集 | json→yolo 转换 + 清洗（1943 张）|

**关键能力**：数据集格式转换（LabelMe→YOLO）、数据清洗（去重/过滤无效框）、train/val 划分。

## 二、训练微调

- **基线**：YOLO26s（COCO 预训练）
- **配置**：imgsz 800 / batch 8 / 50 epochs
- **增强**：mosaic + copy_paste + degrees=90（小目标专用）
- **产出**：best.pt

## 三、评估优化

| 指标 | 说明 |
|---|---|
| mAP@0.5 | 整体检测效果 |
| mAP@0.5:0.95 | 定位精度 |
| AP_small | 小目标效果 |

**优化手段**：阈值搜索 / SAHI 切片推理（小目标 +60%）。

## 四、部署上线

- 导出 ONNX（跨平台）/ TensorRT（GPU 加速）
- 实时推理（webcam / 视频）
- 输出坐标/类别供业务集成

## 五、应用扩展

| 应用 | 状态 |
|---|---|
| VisDrone 小目标检测 | 主项目 |
| 钢珠检测（电赛）| 进行中 |
| 风电叶片缺陷检测 | 已有 |

## 技术亮点

- **小目标检测方法论**：高分辨率 + P2头 + SAHI 切片（四板斧）
- **最新 YOLO26**：2026 前沿模型实践
- **完整工程闭环**：数据→训练→评估→部署全流程
- **可复用范例**：任何检测任务按此闭环（[tutorial/07](tutorial/07-YOLO应用典型闭环.md)）
