## 6. SAHI 切片推理优化 (2026-06-01)

### 6.1 方案选择

SAHI (Slicing Aided Hyper Inference) 将大图切成重叠小块分别检测再合并，零训练成本提升小目标检测精度。

### 6.2 实验配置

| 参数 | 值 |
|------|-----|
| 切片尺寸 | 640×640 |
| 重叠率 | 0.2 (20%) |
| 置信度阈值 | 0.25 |
| 后处理 | NMS (match_threshold=0.5) |
| 基础模型 | YOLOv8s Improved (best.pt) |

### 6.3 评估结果

| 指标 | Improved | SAHI | 提升 |
|------|----------|------|------|
| mAP@0.5 | 0.4258 | **0.4523** | **+6.2%** |
| mAP@0.5:0.95 | 0.2453 | **0.2539** | **+3.5%** |

推理速度: 0.26s/张 (548 张共 141.8s)

### 6.4 各类别对比

| 类别 | Improved | SAHI | 提升 |
|------|----------|------|------|
| bicycle | 0.176 | 0.255 | **+44.9%** |
| pedestrian | 0.479 | 0.557 | +16.3% |
| people | 0.351 | 0.388 | +10.6% |
| bus | 0.589 | 0.628 | +6.6% |
| motor | 0.487 | 0.519 | +6.6% |
| tricycle | 0.308 | 0.321 | +4.2% |
| truck | 0.405 | 0.411 | +1.5% |
| car | 0.815 | 0.819 | +0.5% |
| van | 0.478 | 0.473 | -1.0% |
| awning-tricycle | 0.171 | 0.151 | -11.7% |

### 6.5 分析

- 小目标提升显著: bicycle +44.9%, pedestrian +16.3%
- 大目标基本持平或略有下降
- awning-tricycle 下降原因: 样本极少且切片后上下文信息丢失

## 7. 零训练优化实验 (2026-06-08)

### 7.1 实验目标

在 SAHI 基础上，探索三种零训练成本的优化策略: 置信度阈值搜索、TTA、多模型集成。

### 7.2 实验 1: 置信度阈值网格搜索

以 SAHI (conf=0.05) 收集全部 81344 条预测，然后按不同阈值过滤评估:

| conf | mAP@0.5 | mAP@0.5:0.95 | 预测数 |
|------|---------|--------------|--------|
| 0.05 | **0.4903** | **0.2677** | 81344 |
| 0.10 | 0.4826 | 0.2649 | 63271 |
| 0.15 | 0.4733 | 0.2618 | 53716 |
| 0.20 | 0.4635 | 0.2581 | 46964 |
| 0.25 | 0.4523 | 0.2539 | 41888 |
| 0.30 | 0.4389 | 0.2487 | 37733 |
| 0.35 | 0.4226 | 0.2414 | 34024 |
| 0.40 | 0.4021 | 0.2332 | 30810 |

**最优阈值**: 0.05, mAP@0.5=0.4903 (+8.4% vs SAHI conf=0.25)

### 7.3 实验 2: SAHI + TTA

对原图和水平翻转图分别 SAHI 推理，per-class NMS 合并:

| 指标 | SAHI | SAHI+TTA | 提升 |
|------|------|----------|------|
| mAP@0.5 | 0.4523 | 0.4710 | +4.1% |
| mAP@0.5:0.95 | 0.2539 | 0.2636 | +3.8% |

推理耗时: 789s (1.44s/张)，约为普通 SAHI 的 5.6 倍

### 7.4 实验 3: 多模型集成

YOLOv8n (×0.7) + YOLOv8s (×1.0) 加权融合:

| 指标 | 结果 |
|------|------|
| mAP@0.5 | 0.3535 |
| mAP@0.5:0.95 | 0.2140 |
| 推理耗时 | 91.1s (0.17s/张) |

**分析**: 集成效果不佳 (0.3535 < 0.4258)，因基线模型质量过低拉低整体

### 7.5 综合排名

| # | 方法 | mAP@0.5 | vs 基线 |

## 8. 第五轮实验: P2 小目标检测头 + CBAM 注意力 (2026-06-10)

### 8.1 实验目标

在标准 YOLOv8s 基础上，通过架构层面的改进进一步提升小目标检测能力:
1. 增加 P2 (160×160) 检测层，专门检测 <16px 的小目标
2. 在 Backbone 的 P2/P3/P4 层后插入 CBAM 注意力模块

### 8.2 模型架构

**YOLOv8s-P2-CBAM** (32 层, 14.5M 参数):

| 组件 | 说明 |
|------|------|
| Backbone | CSPDarknet + 3 个 CBAM 注意力模块 |
| Neck | FPN + PAN，双向特征融合 |
| Head | 4 层检测头: P2(160×160) + P3(80×80) + P4(40×40) + P5(20×20) |
| 检测点 | 34000 (vs 标准 8400) |

**P2 检测头设计**:
- 从 P3 特征图上采样 2 倍 → 与 Backbone P2 特征拼接 → C2f → 160×160 输出
- 25600 个检测点专门覆盖小目标区域

**CBAM 注意力**:
- 通道注意力: 学习各通道重要性权重
- 空间注意力: 学习各空间位置重要性权重
- 插入位置: Backbone 层 3 (P2 后)、层 6 (P3 后)、层 9 (P4 后)

### 8.3 实验配置

| 参数 | 值 |
|------|-----|
| 模型 | YOLOv8s + P2 + CBAM |
| 输入尺寸 | 800×800 |
| Batch Size | 8 |
| Epochs | 80 |
| 优化器 | Auto (SGD) |
| 学习率 | lr0=0.01, lrf=0.01 |
| 预训练 | 部分 (Backbone 前 3 层 from COCO) |
| 数据增强 | MixUp(0.15) + CopyPaste(0.1) + Erasing(0.5) |
| Mosaic 关闭 | 最后 15 epochs |
