# 视觉编码器：CNN/YOLO vs ViT —— 通向 VLA 的桥

> 模块 1 和模块 2 的规划衔接点：理解"视觉如何被编码"，
> 从 CNN（检测）到 ViT（Transformer 视觉），这是通向 VLA（视觉-语言-动作）的关键桥梁。

## 一、为什么要讲视觉编码器

从学习路径看：
```
M1 CNN分类 → M2 YOLO检测 → M3 VLA(视觉+语言+动作)
              ↑ 都依赖"视觉编码器" ↑
```

VLA 模型（如 Qwen3-VL）的**视觉 backbone 就是 ViT**。
不理解 ViT，就无法理解 VLA 如何"看懂图片"。
所以这是**从检测通向 VLA 的桥**。

## 二、视觉编码器是什么

**一句话**：把图像（像素矩阵）转换为"机器能理解的特征向量/序列"。

```
图像 (224x224x3) → 编码器 → 特征 (序列/向量)
   像素太小、太原始          → 语义信息（"这是车"、"这是钢珠"）
```

视觉编码器是视觉模型的**基础**：分类、检测、VLA 都用它提取特征。

## 三、两种视觉编码器对比

### CNN（卷积神经网络）—— M1/M2 用过

```
图像 → 卷积层堆叠 → 特征图（空间结构保留）
```

**核心思想**：局部感受野 + 权值共享（平移不变性）。
- 从边缘→纹理→部件→物体（逐层抽象）
- YOLO 的 backbone（CSPDarknet）就是 CNN

**特点**：
- ✅ 局部性好，擅长捕捉空间细节
- ✅ 计算高效（卷积共享权重）
- ❌ 感受野有限（需要深层才能看全局）
- ❌ 难以建模长距离依赖（远处的相关性）

### ViT（Vision Transformer）—— VLA 用

```
图像 → 切块(patch) → 线性嵌入 → Transformer编码器 → 特征序列
```

**核心思想**：把图像当"词序列"处理，用自注意力建模全局关系。
1. **Patch Embedding**：把图像切成小块（如16x16），每块映射成向量
2. **Position Embedding**：加位置信息（否则模型不知顺序）
3. **Self-Attention**：每块与其他所有块计算相关性（全局感受野）

**特点**：
- ✅ 全局感受野，建模长距离依赖
- ✅ 灵活（可处理任意分辨率/多模态）
- ❌ 数据需求大（需要大预训练）
- ❌ 计算量大（注意力是平方复杂度）

## 四、YOLO 检测头 vs ViT 视觉编码器（M2 规划要求）

| 维度 | YOLO 检测头（CNN）| ViT 视觉编码器 |
|---|---|---|
| **任务** | 检测（定位+分类）| 特征提取（通用）|
| **结构** | CNN backbone + 检测头 | Transformer 编码器 |
| **视野** | 局部（感受野有限）| **全局**（自注意力）|
| **输出** | 检测框+类别 | 特征序列（语义）|
| **用途** | 目标检测 | **VLA 的视觉 backbone** |
| **多模态** | 单模态（图像）| **支持**（图像+文本）|

**关键分野**：检测关注"哪里有什么"，VLA 关注"图像与语言如何关联并指导动作"。ViT 的全局+多模态特性，使它成为 VLA 的视觉基础。

## 五、为什么 ViT 适合 VLA

1. **全局理解**：VLA 需要理解整个场景（不只是找目标），ViT 的全局注意力适合
2. **多模态对齐**：ViT 的特征可与文本 token 对齐（Transformer 天然统一）
3. **灵活序列**：图像patch、文本token、动作token 都是序列，Transformer 统一处理

```
VLA 内部：
图像 → ViT编码 → 视觉特征 ─┐
指令 → token化 → 文本特征 ─┼→ Transformer → 动作输出
                           ┘
```

## 六、与 M3 的衔接

M3 用 Qwen3-VL（ViT 视觉 backbone + LLM）做 VLA。
本节的 ViT 理解，就是读懂 Qwen3-VL 视觉部分的基础：
- **Patch Embedding** → Qwen3-VL 如何切图
- **Self-Attention** → 如何理解全局场景
- **多模态对齐** → 如何让"看到的"和"听到的"关联

## 七、小结

```
CNN（检测）     → 局部、高效、定位
ViT（Transformer）→ 全局、多模态、理解
VLA = ViT视觉 + LLM语言 → 看+听+做
```

**本节是 M1（CNN 分类）→ M2（YOLO 检测）→ M3（VLA）的桥梁**：
你已理解 CNN（M1/M2），现在理解 ViT 的全局+多模态特性，
就能明白 VLA 为什么用 ViT 做视觉 backbone。
