## 1. 为什么需要部署优化

训练好的模型是 `.pt`（PyTorch），但生产环境需要更高效的格式：

| 格式 | 用途 | 优势 |
|---|---|---|
| `.pt` | 训练/实验 | 灵活，但慢 |
| `.onnx` | 通用部署 | 跨平台，ONNX Runtime |
| `.engine` | TensorRT | **GPU 加速，快 5 倍+** |

## 2. 导出 ONNX

```python
from ultralytics import YOLO
model = YOLO("best.pt")
model.export(format="onnx", imgsz=800, simplify=True)
```

- `simplify=True`：简化计算图，更小更快
- 产出 `best.onnx`

## 3. 导出 TensorRT（GPU 加速）

```python
model.export(format="engine", imgsz=800, half=True, device=0)
```

- `half=True`：FP16 精度，速度翻倍
- `device=0`：指定 GPU
- 产出 `best.engine`（RTX 4060 可用）

**TensorRT 加速效果**（RTX 4060）：
- v8s @ 640：单帧 < 10ms
- @ 1280：约 15-25ms（仍 >30FPS）

## 5. SAHI 切片推理（小目标部署）

对小目标检测，SAHI 切片推理能显著提升效果，但慢：

```
直接推理：mAP50 ≈ 18.3，延迟 ~2ms
SAHI 切片：mAP50 ≈ 29.7（+62%），延迟 ~45ms
```

**取舍**：
- 实时场景：直接推理（快）
- 高精度离线：SAHI（准）

## 小结

- 部署：.pt → .onnx → .engine（TensorRT GPU 加速）
- 实时推理：`model.predict(source=0)` 一行
- 小目标：SAHI 精度高但慢，按场景取舍
