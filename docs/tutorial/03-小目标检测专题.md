## 1. 为什么小目标难：信息丢失

VisDrone 是无人机俯拍，**87% 的目标面积 < 图像 0.3%**，行人平均仅 12-28 像素高。

```
一张 2000×1500 的图里，行人只有 12~28 像素高
→ CNN 5 次下采样（÷32）：12px → <1px
→ 深层特征图上，小目标几乎消失
```

**根源**：不是模型不聪明，而是**下采样导致小目标信息丢失**。

### 探究
为什么分类任务不太怕小目标，检测任务却很怕？
> 答：分类只需要"判断整图有没有猫"，即使猫小，整体特征仍在；检测要"精确定位"，小目标下采样后定位信息丢失。

## 2. 小目标四板斧（跨版本通用解法）

按收益排序：

### 板斧1：提高输入分辨率（收益最大，+25% mAP）
```
imgsz=640  → 行人 12px → ~4px
imgsz=1280 → 行人 12px → ~8px（大一倍！）
```
目标在输入更大 → 下采样后特征仍存 → 检测更准。

### 板斧2：P2 检测头（更细特征图）
```
标准：P3/P4/P5（下采样 8/16/32 倍）
P2：加 stride=4 检测头 → 小目标信息更全
```

### 板斧3：SAHI 切片推理（大图切小，目标"变大"）
```
2000×1500 大图 → 切成 640×640 块 → 分别检测 → 合并
VisDrone：直接推理 mAP≈18.3 → SAHI ≈29.7（+62%）
```

### 板斧4：数据增强（更多小目标变体）
```
copy_paste / mosaic / 随机旋转 → 模型更鲁棒
```

## 3. 本项目如何应用（对应关系）

| 高分辨率 | Baseline 640 → Improved 800px | mAP 0.298→0.426 |

**关键认知**：项目的每一步都是在解决"小目标信息丢失"这个根本问题。

## 小结

- 小目标难 = 下采样信息丢失
- 四板斧：高分辨率 > P2头 > SAHI切片 > 数据增强
- 本项目 = 四板斧的实际应用
