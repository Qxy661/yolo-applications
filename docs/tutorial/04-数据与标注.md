| 项 | 值 |

## 2. 两种标注格式

**VisDrone 原始格式**（每行 8 字段，逗号分隔，像素坐标）：
```
<bbox_left>,<bbox_top>,<bbox_width>,<bbox_height>,<score>,<category>,<truncation>,<occlusion>
例：100,200,50,60,1,4,0,0
```

**YOLO 格式**（每行 5 值，归一化，类别从 0 开始）：
```
<class> <x_center> <y_center> <width> <height>
例：3 0.125 0.133 0.025 0.04
```

### 探究
YOLO 为什么用归一化坐标？
> 答：归一化(0-1)不依赖图像尺寸，任何分辨率的图共用一套标注，跨分辨率可迁移。

## 3. 转换四步（本项目 download_data.py）

### 第1步：跳过无效标注
```python
if cls_id == 0 or score < 0:
    continue
```
- `category=0`：忽略区域（不参与检测）
- `score<0`：训练集无效标注
- 必须过滤，否则当负样本误导训练

### 第2步：类别 1→0 映射
```python
cls_yolo = VISDRONE_TO_YOLO[cls_id]   # 1-10 → 0-9
```
YOLO 要求类别从 0 开始。

### 第3步：像素框 → 归一化中心+尺寸
```python
x_center = (x + w/2) / img_w
y_center = (y + h/2) / img_h
w_norm = w / img_w
h_norm = h / img_h
```
核心转换：像素坐标 → 归一化（0-1）。

### 第4步：写入 .txt（同名在 labels/）
```python
f"{cls} {x_center:.6f} {y_center:.6f} {w_norm:.6f} {h_norm:.6f}"
```

## 4. 为什么理解转换重要

所有检测项目第一步都是"数据集 → YOLO 格式"：
- 自定义数据集：自己标注 → 转 YOLO
- 公开数据集：如 VisDrone/COCO → 转 YOLO
- 理解了转换，就能处理任何数据集

## 5. 数据划分

```
images/train + labels/train    训练
images/val   + labels/val      验证（不参与训练）
images/test  + labels/test     测试（最终验证）
```

**注意**：val 和 test 必须分开——val 用来调参，test 用来最终验证（避免用验证集调参导致过拟合）。

### 本项目的缺口
- 只有 train/val，**无 test**（评估只在 val 上，最终效果未经独立验证）→ 待补齐

## 小结

- VisDrone：10 类、2000×1500、87% 小目标
- 转换：跳过无效 → 类别映射 → 像素转归一化 → 写 txt
- 归一化坐标跨分辨率通用
- val/test 必须分开
