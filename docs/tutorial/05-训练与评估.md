## 1. 训练配置（小目标检测）

用 ultralytics 训练，核心参数：

| 参数 | 值 | 为什么 |
|---|---|---|
| `imgsz` | 640→800→1280 | **小目标用大分辨率**（信息保留）|
| `batch` | 4-8（8GB显存）| 受显存限制 |
| `epochs` | 50-150 | VisDrone 收敛慢，需多轮 |
| `mosaic` | 1.0 | 拼图增强，多尺度 |
| `copy_paste` | 0.3 | 密集小目标增益明显 |
| `degrees` | 90 | 无人机俯拍方向任意 |
| `close_mosaic` | 10 | 最后10轮关mosaic防过拟合 |

**本项目实测**（YOLO26n @ 640）：1 epoch ≈ 3.8 分钟 → 10 epochs ≈ 40 分钟。

## 2. 训练命令（本项目）

```python
from ultralytics import YOLO
model = YOLO("yolo26s.pt")        # 2026 最新模型
model.train(data="visdrone.yaml",
            imgsz=800, epochs=50, batch=8,
            mosaic=1.0, copy_paste=0.3, degrees=90,
            device=0)
```

## 3. 评估指标：mAP 家族

| 指标 | 含义 | 本项目参考 |
|---|---|---|
| mAP@0.5 | IoU=0.5 单阈值 AP 均值 | baseline 0.298 → improved 0.426 |
| mAP@0.5:0.95 | IoU 0.5→0.95 平均（更严）| 明显低于 mAP@0.5（定位难）|
| **AP_small** | 面积 < 32² 像素目标 | **小目标核心指标** |
| AP_medium/large | 对照 | 通常比 small 高 |

**关键**：小目标检测要**重点看 AP_small**——它衡量"小目标到底检测得怎么样"。

## 4. 评估命令

```python
model.val(data="visdrone.yaml", conf=0.001, iou=0.6)
# 输出 mAP50, mAP50-95, 每类 AP, 分尺度 AP_small/medium/large
```

## 5. 数据增强（小目标专用）

| 增强 | 作用 |
|---|---|
| mosaic | 拼4图，多尺度目标 |
| copy_paste | 复制小目标到别处，增加数量 |
| mixup | 图像混合 |
| scale=0.5 | 制造更小目标 |
| degrees=90 | 任意方向（无人机）|

**研究结论**：增强强度要适度（过度反而降效果）。

## 6. 训练验证的流程（推荐）

```
1. 快速验证（10 epochs, 小模型）→ 确认收敛、无报错
2. 正式训练（大模型 + 大分辨率 + 强增强）→ 完整效果
3. 评估 mAP/AP_small → 判断效果
4. 可选：SAHI 切片推理 → 进一步提升小目标
```

## 小结

- 训练：小目标用大 imgsz + 强增强
- 评估：mAP@0.5 为主，**AP_small 为小目标亮点**
- 流程：快速验证 → 正式训练 → 评估 → 优化
