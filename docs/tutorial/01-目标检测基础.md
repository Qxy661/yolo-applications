# 01 · 目标检测基础

> 目标检测是计算机视觉的核心任务之一。本教程从分类出发，建立检测的完整知识体系。
> 这是 **docs/tutorial/** 知识体系的第一篇，配套本项目（VisDrone 小目标检测）。

## 前置知识

- 熟悉深度学习分类（CNN/卷积/损失/训练循环）
- 本项目是 YOLO 小目标检测，需要先理解"检测是什么"

## 1. 目标检测 vs 分类：本质区别

| | 分类 | 检测 |
|---|---|---|
| 输入 | 一张图 | 一张图 |
| 输出 | 一个类别标签 | 多个（框 + 类别）|
| 回答的问题 | 图中有什么？ | 东西在哪 + 是什么？ |
| 输出数量 | 固定（1个）| 可变（取决于物体数量）|

**核心**：检测 = **定位（回归 bbox）** + **分类（类别）** 两个任务同时做。

### 探究
为什么检测输出是"动态数量"而分类是固定 1 个？
> 答：图里物体数量不定。检测要找出每个物体并分别框出+分类，所以输出数量随图变化。

## 2. Bounding Box（边界框）

检测的"定位"用 **bbox** 表示，常见两种表示：

```
方式1 像素坐标:  (x1, y1, x2, y2)    左上角 + 右下角
方式2 中心+尺寸: (cx, cy, w, h)      中心点 + 宽高
```

**关键**：bbox 是连续值 → 定位是**回归任务**；类别是离散值 → 分类是离散任务。检测 = 两者结合。

### 探究
为什么 "w"（宽）一定是正数，而坐标可以是任意值？
> 答：宽高是物理尺寸（恒正）；坐标是位置（可正可负，取决于参考系）。

## 3. IoU（交并比）

检测模型预测框和真实框（ground truth）的重合度：

```
IoU = 两框交集面积 / 两框并集面积
```

| IoU 值 | 含义 |
|---|---|
| 1.0 | 完全重合（完美）|
| > 0.5 | 通常算"检测对了" |
| 0 | 完全不重合（失败）|

**IoU 是检测的核心度量**：判断"框准不准"，就看和真值框的 IoU。

### 探究
为什么用 IoU 而不是直接比较坐标差？
> 答：坐标差受图像尺寸影响（大图差10px不算错），IoU 是**归一化的比例**，跨尺寸可比。

## 4. mAP（mean Average Precision）

mAP 综合**精确率（Precision）**和**召回率（Recall）**：

| 指标 | 含义 |
|---|---|
| Precision | 预测的框里，多少是对的（误检少）|
| Recall | 真实物体里，多少被找到（漏检少）|
| mAP@0.5 | IoU=0.5 时的 AP 均值 |
| mAP@0.5:0.95 | IoU 从 0.5 到 0.95 的平均（更严格）|

**直觉**：mAP 越大，检测越"又准又全"。

### 本项目中的 mAP
- Baseline mAP@0.5 = 0.298
- Improved mAP@0.5 = 0.426
- SAHI 切片后 mAP@0.5 = 0.490

## 5. 检测框架：两阶段 vs 单阶段

| 类型 | 代表 | 思路 | 特点 |
|---|---|---|---|
| 两阶段 | Faster R-CNN | 先找候选框，再分类 | 准但慢 |
| 单阶段 | **YOLO** | 一步直接预测框+类别 | 快，够准 |

**本项目用 YOLO（单阶段）**——因为无人机检测需要实时性。

## 小结

- 检测 = 定位(bbox) + 分类，输出动态数量
- bbox 用 4 个数表示（坐标或中心+尺寸）
- IoU 衡量预测框和真值框的重合度
- mAP 综合精确率+召回率，是标准评估指标
- 单阶段（YOLO）适合实时场景
