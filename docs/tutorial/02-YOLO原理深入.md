# 02 · YOLO 原理深入（跨版本通用）

> YOLO 系列不断演进（v8→v11→v12→YOLO26），但核心思想不变。
> 本课讲**跨版本通用的原理**——理解了这些，任何 YOLO 版本都能快速上手。
> 2026 年最新为 YOLO26（NMS-free 端到端设计），但下面的思想全部适用。

## 前置

- [01 · 目标检测基础](01-目标检测基础.md)

## 1. YOLO 核心思想：You Only Look Once

```
传统两阶段：先找候选区 → 再分类（看两次）
YOLO：一次前向直接预测所有物体（只看一次）
```

**为什么快**：一次前向传播（一个 CNN 过一遍），不逐区域处理。

## 2. 网格机制（检测怎么"一次"完成）

```
图像分成 S×S 网格
每格预测：若有物体中心落在格子 → 预测 bbox + 类别
```

**直觉**：把图切格子，每格说"有没有物体、在哪、是什么"，所有格一起覆盖全图。

## 3. 三部分架构（所有 YOLO 通用）

```
输入 → [Backbone 提特征] → [Neck 多尺度融合] → [Head 预测]
```

| 部分 | 作用 |
|---|---|
| Backbone | 提取特征（和分类 CNN 一样，你 M1 已懂）|
| **Neck** | 融合多尺度（浅层抓小目标，深层抓大目标）|
| Head | 输出 bbox + 类别 |

**Neck 为什么关键**：检测要处理不同大小物体，必须多尺度融合。

## 4. Anchor-Free（YOLOv8 起，跨版本沿用）

```
Anchor-Based（旧）：预测对预设锚框的偏移量，锚框需手动设计
Anchor-Free（新）：每个网格点直接预测 (x,y,w,h)，简洁泛化好
```

YOLOv8 及以后均为 Anchor-Free，无需为数据集调锚框。

## 5. 特征金字塔 FPN/PANet（小目标核心）

```
640 输入下采样 5 次：P1(320) ... P5(20)
P5 一个像素对应原图 32×32 → 小目标在深层消失
```

**FPN**：高层语义下传，让低层也有强语义。
**PANet**：加自底向上路径，双向融合位置+语义。

YOLO 用 FPN+PANet，P3/P4/P5 多尺度输出。

## 6. 损失核心思想（跨版本不变）

```
总损失 = 定位(框准不准) + 置信度(有没有物体) + 分类(类别对不对)
```

- 定位：IoU 家族（IoU→GIoU→DIoU→CIoU），解决"框不准"
- 置信度/分类：BCE（M1 学过）

**理解损失思想 > 记架构细节**——前者跨版本迁移，后者易过时。

## 7. YOLO 版本演进（了解即可）

| 版本 | 关键点 |
|---|---|
| YOLOv1-3 | 开山/多尺度 |
| YOLOv5-8 | 工程化/Anchor-Free |
| YOLO11-14 | 注意力/统一框架 |
| **YOLO26** | **NMS-free 端到端、CPU +43%**（2026 旗舰）|

**启示**：用最新 ultralytics 库（一个库通吃所有版本），训练时选最新模型即可。

## 小结

- YOLO = 一次前向完成检测（网格机制）
- Backbone + Neck + Head 三部分
- Anchor-Free + FPN/PANet 是多尺度小目标基础
- 损失 = 定位 + 置信度 + 分类（跨版本不变）
- **用最新版本，懂通用原理**
