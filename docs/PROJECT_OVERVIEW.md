# 项目概览：YOLO 小目标检测（应用流程闭环）

> 一个完整的 YOLO 检测应用：从数据准备到部署上线的全流程。
> 以"闭环"为组织主线，可复用于任何检测任务。

## 闭环全景

```
┌─ 数据准备 ──────────────────────────────────────┐
│ VisDrone(无人机) / SteelBall(实时) / WindTurbine │
│ → 获取 → 清洗 → 转换 → 划分 → data.yaml          │
├─ 训练微调 ──────────────────────────────────────┤
│ 基线(yolo26s) → 微调 → best.pt → 调参优化        │
├─ 评估优化 ──────────────────────────────────────┤
│ mAP / AP_small → 阈值搜索 / SAHI 切片            │
├─ 部署上线 ──────────────────────────────────────┤
│ ONNX / TensorRT → 实时推理 → 业务集成            │
└────────────────────────────────────────────────┘
```
