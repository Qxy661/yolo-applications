# 小目标检测评估与优化方法论

> 不只是看 mAP，而是综合诊断 → 针对小目标场景痛点做重点加权优化。
> 这是本项目最具技术含金量的部分。

## 为什么不能只看 mAP

mAP 是整体平均，**掩盖了问题**：
- 漏检多 + 误检少 → mAP 可能还行，但很多目标没检出
- 小目标差 + 大目标好 → mAP 被平均，小目标问题被掩盖

所以必须**综合多个指标诊断**。

## 第一步：综合评估（诊断）

| 指标 | 诊断什么 | 意义 |
|---|---|---|
| **Precision (P)** | 误检多不多 | 检出的框里多少是对的 |
| **Recall (R)** | 漏检多不多 | 真目标里多少被检出 |
| **mAP@0.5** | 整体效果 | 粗略评估 |
| **mAP@0.5:0.95** | 定位精度 | 严格评估 |
| **AP_small** | **小目标专项** | 小目标（<32px）效果 |
| **AP_medium/large** | 中/大目标 | 对比 |
| **AP 按类别** | 各类别难点 | 找出最难类 |
| **F1-score** | P/R 平衡 | 最优阈值 |
| **混淆矩阵** | 漏检/误检可视化 | 具体哪类出错 |

## 第二步：诊断痛点

```
R 低（漏检多）      → 小目标没被检出（小目标检测典型问题）
P 低（误检多）      → 背景被当目标
AP_small << AP      → 小目标是瓶颈
混淆矩阵看列        → 哪类被漏检最多
混淆矩阵看行        → 哪类被误检最多
```

## 第三步：针对小目标场景优化

### 针对漏检（小目标核心痛点）

| 手段 | 原理 | 效果 |
|---|---|---|
| **降低 conf 阈值** | 检出更多低置信目标 | 提 R，可能降 P |
| **SAHI 切片推理** | 放大后检测再合并 | 小目标 +60% |
| **更高分辨率 (imgsz)** | 小目标更清晰 | 提 R |
| **P2 检测头** | 高分辨率特征 | 提小目标 AP |
| **Focal Loss** | 平衡难例 | 提小目标 |
| **小目标数据增强** | 更多小目标样本 | 提 R |

### 针对误检（反光/背景干扰）
- 提高置信度阈值
- 后处理过滤（如钢珠的高光校验）
- 更多负样本

## 关键权衡：P vs R（漏检 vs 误检）

**核心矛盾**：
```
提 Recall（少漏检） → 可能降 Precision（多误检）
提 Precision（少误检）→ 可能降 Recall（多漏检）
```

**平衡方法**：
1. **F1 最优阈值**：找 P/R 平衡点
2. **PR 曲线**：看不同阈值下权衡
3. **按场景加权**：电赛要"不漏检"（R优先）vs 部署要"少误检"（P优先）

## 本项目应用（VisDrone）

**场景特点**：无人机俯拍，目标小（几个像素），背景复杂
**核心痛点**：漏检（R 偏低是预期的）
**优化重点**：
1. 训练时：高分辨率 + 强增强（已做）
2. 评估后：SAHI 切片推理（重点，提小目标）
3. 阈值：按 F1 找最优 conf

## 方法论的价值

1. **不是盲调**：先诊断（看数据）再优化（针对痛点）
2. **可复现**：每次优化有明确依据
3. **场景导向**：不同场景加权不同（漏检 vs 误检权衡）
4. **作品集亮点**：体现"会评估、会诊断、会优化"的工程能力
