## 2. 技术原理

### 2.1 SAHI 核心思想

SAHI (Slicing Aided Hyper Inference) 的核心思想是：将高分辨率大图切成重叠小块，分别送入检测模型推理，再将各切块的检测结果合并。

```
┌─────────────────┐     ┌───┬───┬───┐     ┌───────────┐
│  2000×1500 原图  │ ──→ │ 1 │ 2 │ 3 │ ──→ │ NMS 合并   │ ──→ 最终结果
│                 │     │ 4 │ 5 │ 6 │     │ 检测框去重  │
└─────────────────┘     └───┴───┴───┘     └───────────┘
                        切片 (重叠20%)
```

### 2.2 为什么 SAHI 有效？

**问题**: VisDrone 图片分辨率 ~2000×1500，直接缩放到 640×640 时：
- 15px 目标 → 6.4px（信息严重丢失）
- 30px 目标 → 12.8px（勉强可检测）

**SAHI 解决方案**: 将原图切成 640×640 小块时：
- 15px 目标 → 15px（保持原始分辨率）
- 30px 目标 → 30px（保持原始分辨率）
- 小目标在切块中像素占比大幅提高

### 2.3 切片参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 切片尺寸 | 640×640 | 匹配模型输入 |
| 重叠率 | 20% | 防止目标被切断 |
| 后处理 | NMS | 跨切块去重 |
| NMS 阈值 | 0.5 | IoU 阈值 |

### 2.4 重叠切片的作用

```
切片 1: [████████░░]  目标在右边缘，可能被切断
切片 2: [░░████████]  目标在左边缘，完整检测
         重叠区域 ↑
```

20% 重叠确保每个目标至少在一个切块中完整出现。

## 4. 实验过程

### 4.1 执行流程

```
1. 加载 YOLOv8s Improved 模型
2. 对每张验证图片:
   a. 切片: 2000×1500 → 多个 640×640 切块 (重叠20%)
   b. 推理: 每个切块独立送入模型
   c. 合并: 跨切块 NMS 去重
3. 收集所有图片的检测结果
4. 使用 pycocotools 评估 mAP
```

### 4.2 推理耗时

| 项目 | 值 |
|------|-----|
| 总耗时 | 132.3 秒 |
| 每张图片 | 0.24 秒 |
| 图片数量 | 548 张 |
| 吞吐量 | ~4.1 张/秒 |

### 4.3 预测数量

| 方法 | 总预测数 | 说明 |
|------|---------|------|
| 直接推理 | ~15,000 | 标准推理 |
| SAHI | 41,888 | 切片推理，更多检测框 |

SAHI 产生更多预测，因为每个切块独立推理，且切块数量多。

## 6. 结果分析

### 6.1 关键发现

1. **小目标提升显著**: bicycle (+44.9%)、pedestrian (+16.3%)，验证了 SAHI 对小目标的有效性
2. **大目标基本持平**: car (+0.5%)、truck (+1.5%)，大目标不受切片影响
3. **零训练成本**: 不需要重新训练模型，仅改变推理策略
4. **推理速度可接受**: 0.24s/张，满足实时性要求

### 6.2 SAHI 为什么对小目标有效？

| 目标 | 原图像素 | 640 输入像素 | SAHI 切块像素 | 提升 |
|------|---------|-------------|-------------|------|
| bicycle 15px | 15px | 6.4px | 15px | 2.3× |
| pedestrian 20px | 20px | 8.5px | 20px | 2.3× |
| car 60px | 60px | 25.6px | 60px | 2.3× |

SAHI 保持了目标的原始像素分辨率，避免了缩放导致的信息丢失。

### 6.3 下降类别分析

**awning-tricycle (-11.7%)**:
- 样本极少（仅 532 个实例）
- 切片后上下文信息丢失，模型缺乏足够的上下文来识别这类稀有目标
- 该类别在切块中出现频率更低

**van (-1.0%)**:
- 轻微波动，可能由 NMS 阈值导致

### 6.4 与直接推理的对比

| 维度 | 直接推理 | SAHI |
|------|---------|------|
| mAP@0.5 | 0.4258 | 0.4523 |
| 推理速度 | ~0.05s/张 | 0.24s/张 |
| 计算成本 | 1× | ~4.8× |
| 小目标效果 | 差 | 好 |
| 大目标效果 | 好 | 好 |

## 7. SAHI 优缺点

### 7.1 优点

1. **零训练成本**: 不需要修改模型或重新训练
2. **即插即用**: 可应用于任何检测模型
3. **小目标提升显著**: 对 <32px 目标提升 10~45%
4. **实现简单**: 使用 SAHI 库，几行代码即可

### 7.2 缺点

1. **推理速度下降**: 约 4.8× 的计算开销
2. **上下文丢失**: 切片后目标缺乏全局上下文
3. **稀有类别可能下降**: 如 awning-tricycle (-11.7%)
4. **内存占用增加**: 需要同时处理多个切块
