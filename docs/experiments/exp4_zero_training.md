# 实验四：零训练优化实验

> 置信度阈值搜索 + TTA + 多模型集成
> 实验日期: 2026-06-08
> 实验者: 小羊

---

## 1. 实验目标

在 SAHI 切片推理基础上，进一步探索三种零训练成本的后处理优化策略，最大化不修改模型前提下的检测精度。

**核心问题**: 不训练、不改模型，仅优化后处理策略，还能提升多少？

---

## 2. 实验设计

### 2.1 三种零训练策略

| 策略 | 原理 | 预期效果 |
|------|------|---------|
| 置信度阈值搜索 | 找到最优置信度过滤阈值 | 中等 |
| TTA (测试时增强) | 水平翻转推理后合并 | 中等 |
| 多模型集成 | 多个模型加权融合 | 较高 |

### 2.2 递进逻辑

```
SAHI (conf=0.25) → mAP@0.5 = 0.4523
    ↓
置信度阈值搜索 → 找到最优 conf=0.05
    ↓
SAHI(conf=0.05) → mAP@0.5 = 0.4903 (+8.4%)
    ↓
SAHI + TTA → mAP@0.5 = 0.4710 (+4.1%)
    ↓
多模型集成 → mAP@0.5 = 0.3535 (效果不佳)
```

---

## 3. 策略一：置信度阈值网格搜索

### 3.1 方法原理

置信度阈值控制检测框的过滤：阈值越高，保留的检测框越少（更精确但可能漏检）；阈值越低，保留的检测框越多（更全面但可能误检）。

**关键洞察**: SAHI 切片推理后，小目标的置信度可能被分散到多个切块中。降低阈值可以保留更多真实检测。

### 3.2 实验方法

1. 使用 SAHI (conf=0.05) 收集全部 81,344 条预测
2. 按不同置信度阈值过滤后评估
3. 找到 mAP@0.5 最优的阈值

### 3.3 网格搜索结果

| 置信度阈值 | mAP@0.5 | mAP@0.5:0.95 | 预测数 | vs SAHI(0.25) |
|-----------|---------|--------------|--------|--------------|
| **0.05** | **0.4903** | **0.2677** | 81,344 | **+8.4%** |
| 0.10 | 0.4826 | 0.2649 | 63,271 | +6.7% |
| 0.15 | 0.4733 | 0.2618 | 53,716 | +4.6% |
| 0.20 | 0.4635 | 0.2581 | 46,964 | +2.5% |
| 0.25 | 0.4523 | 0.2539 | 41,888 | 基准 |
| 0.30 | 0.4389 | 0.2487 | 37,733 | -3.0% |
| 0.35 | 0.4226 | 0.2414 | 34,024 | -6.6% |
| 0.40 | 0.4021 | 0.2332 | 30,810 | -11.1% |

### 3.4 分析

**最优阈值**: conf=0.05，mAP@0.5=0.4903

**为什么低阈值更好？**

1. **SAHI 的特殊性**: 切片推理导致同一目标在多个切块中被检测，置信度被分散
2. **低阈值保留更多检测**: COCOeval 的 AP 计算不依赖置信度排序，而是按 IoU 匹配
3. **小目标的置信度天然较低**: 降低阈值可以保留更多小目标检测

**阈值-精度曲线**:

```
mAP@0.5
0.50 ┤ ● 0.05 (最优)
0.48 ┤   ● 0.10
0.46 ┤     ● 0.15
     │       ● 0.20
0.44 ┤         ● 0.25 (原SAHI)
0.42 ┤           ● 0.30
0.40 ┤             ● 0.35
     │               ● 0.40
0.38 ┼─────────────────────→ conf
    0.05  0.10  0.15  0.20  0.25  0.30  0.35  0.40
```

## 4. 策略二：SAHI + TTA（测试时增强）

### 4.1 方法原理

TTA (Test Time Augmentation) 在推理时对输入进行增强，将增强后的结果与原图结果合并：

```
原图 ──→ SAHI 推理 ──→ 结果 A ──→ NMS 合并 ──→ 最终结果
  ↓
水平翻转 ──→ SAHI 推理 ──→ 结果 B ──┘
```

### 4.2 实验配置

| 参数 | 值 |
|------|-----|
| 增强方式 | 水平翻转 |
| 切片尺寸 | 640×640 |
| 重叠率 | 20% |
| 置信度阈值 | 0.25 |
| 合并方式 | Per-class NMS |

### 4.3 评估结果

| 指标 | SAHI | SAHI+TTA | 提升 |
|------|------|----------|------|
| **mAP@0.5** | 0.4523 | **0.4710** | **+4.1%** |
| **mAP@0.5:0.95** | 0.2539 | **0.2636** | **+3.8%** |
| 总预测数 | 41,888 | 48,373 | +15.5% |

### 4.4 各类别 AP@0.5

| 类别 | SAHI | SAHI+TTA | 提升 |
|------|------|----------|------|
| bus | 0.628 | 0.645 | +2.7% |
| car | 0.819 | 0.834 | +1.8% |
| motor | 0.519 | 0.541 | +4.2% |
| pedestrian | 0.557 | 0.578 | +3.8% |
| people | 0.388 | 0.409 | +5.4% |
| tricycle | 0.321 | 0.353 | +10.0% |
| van | 0.473 | 0.491 | +3.8% |
| truck | 0.411 | 0.431 | +4.9% |
| bicycle | 0.255 | 0.263 | +3.1% |
| awning-tricycle | 0.151 | 0.166 | +9.9% |

### 4.5 推理耗时

| 项目 | SAHI | SAHI+TTA | 倍率 |
|------|------|----------|------|
| 总耗时 | 132.3s | 789.0s | 5.96× |
| 每张图片 | 0.24s | 1.44s | 6.0× |

TTA 需要两次推理（原图 + 翻转），耗时约为普通 SAHI 的 6 倍。

## 5. 策略三：多模型集成

### 5.1 方法原理

将多个不同模型的检测结果加权融合：

```
YOLOv8n 推理 → 结果 A (权重 0.7) ──→ 加权合并 ──→ NMS ──→ 最终结果
YOLOv8s 推理 → 结果 B (权重 1.0) ──┘
```

### 5.2 实验配置

| 参数 | 值 |
|------|-----|
| 模型 1 | YOLOv8n Baseline (mAP@0.5 = 0.2979) |
| 模型 2 | YOLOv8s Improved (mAP@0.5 = 0.4258) |
| 权重 | v8n × 0.7, v8s × 1.0 |
| 合并方式 | 加权 NMS |

### 5.3 评估结果

| 指标 | Ensemble | vs Improved | vs Baseline |
|------|----------|------------|-------------|
| **mAP@0.5** | 0.3535 | -17.0% | +18.7% |
| **mAP@0.5:0.95** | 0.2140 | -12.8% | +28.7% |
| 总预测数 | 70,653 | - | - |
| 推理耗时 | 91.1s | - | - |

### 5.4 各类别 AP@0.5

| 类别 | Ensemble | Improved | 差值 |
|------|----------|----------|------|
| car | 0.715 | 0.815 | -0.100 |
| bus | 0.501 | 0.589 | -0.088 |
| motor | 0.416 | 0.487 | -0.071 |
| pedestrian | 0.409 | 0.479 | -0.070 |
| van | 0.354 | 0.478 | -0.124 |
| truck | 0.330 | 0.405 | -0.075 |
| people | 0.300 | 0.351 | -0.051 |
| tricycle | 0.250 | 0.308 | -0.058 |
| bicycle | 0.147 | 0.176 | -0.029 |
| awning-tricycle | 0.114 | 0.171 | -0.057 |

### 5.5 失败原因分析

**集成效果不佳（0.3535 < 0.4258）的原因**:

1. **基线模型质量过低**: YOLOv8n mAP@0.5 = 0.2979，其低质量预测拉低了整体
2. **权重设计不合理**: 给基线模型 0.7 权重过高，应降低或不使用
3. **模型差异不够**: YOLOv8n 和 YOLOv8s 架构相似，缺乏多样性
4. **NMS 阈值**: 合并后的 NMS 可能过滤掉了正确检测

**改进方向**: 如果要使用集成，应选择质量相近的模型，或使用更复杂的集成策略（如加权框融合 WBF）。

### 6.3 关键发现

## 7. 实验结论

### 7.1 最优策略

**SAHI + conf=0.05** 是零训练优化的最优策略：
- mAP@0.5 = 0.4903
- 较基线提升 +64.6%
- 较改进模型提升 +15.1%
- 推理速度 0.24s/张，可接受

### 7.2 策略选择建议

| 场景 | 推荐策略 | 理由 |
|------|---------|------|
| 追求最高精度 | SAHI(conf=0.05) | mAP@0.5 最高 |
| 平衡精度和速度 | SAHI(conf=0.25) | 精度略低但更稳定 |
| 精度要求极高 | SAHI+TTA | 多 4% 提升但 6× 耗时 |
| 不推荐 | 多模型集成 | 基线质量不足时效果差 |

### 7.3 经验总结

1. **低置信度阈值在 SAHI 场景下有效**: 切片推理分散了置信度，低阈值保留更多真实检测
2. **TTA 是可靠的提升手段**: 水平翻转增强对对称性目标效果好
3. **集成需要高质量基线**: 低质量模型会拉低整体性能
4. **零训练优化潜力巨大**: 不修改模型，仅优化推理策略即可获得 64.6% 的累计提升
