# 实验二：改进实验

> YOLOv8s + 800px + 强数据增强
> 实验日期: 2026-05-20
> 实验者: 小羊

---

## 1. 实验目标

针对基线实验暴露的问题，从模型容量、输入分辨率、数据增强三个维度进行改进，验证多维度协同优化对小目标检测的提升效果。

**核心问题**: 模型升级 + 更大输入 + 更强增强，能带来多少提升？

---

## 2. 改进方案

### 2.1 改进项总览

| 维度 | 基线 | 改进 | 改进理由 |
|------|------|------|---------|
| 模型 | YOLOv8n (3.2M) | YOLOv8s (11.2M) | 更多参数提供更强特征表达能力 |
| 输入尺寸 | 640×640 | 800×800 | 保留更多小目标像素信息 |
| 数据增强 | 默认 | MixUp+CopyPaste+Erasing | 增加数据多样性，防止过拟合 |
| 训练轮数 | 50 | 80 | 更充分的训练收敛 |

### 2.2 为什么选择这些改进？

**模型升级 (YOLOv8n → YOLOv8s)**:
- 参数量从 3.2M 增至 11.2M（3.5×）
- FLOPs 从 8.7G 增至 28.6G（3.3×）
- COCO mAP 从 37.3 增至 44.9（+7.6%）
- 仍属轻量级模型，推理速度快

**增大输入 (640 → 800)**:
- 小目标在原图中仅 10~30px
- 640 输入下，15px 目标缩放后仅 6.4px，信息严重丢失
- 800 输入下，15px 目标缩放后为 8px，保留更多细节
- 代价: 内存增加 ~56%，batch 从 16 降至 8

**更强数据增强**:
- MixUp: 两张图混合，增加样本多样性
- CopyPaste: 复制粘贴目标，增加小目标样本
- 随机擦除: 模拟遮挡，提升鲁棒性

## 7. 结果分析

### 7.1 关键发现

1. **整体提升显著**: mAP@0.5 从 29.79% 提升至 42.58%，绝对提升 +12.79%
2. **小目标提升最大**: bicycle (+183.9%)、awning-tricycle (+71.0%)、tricycle (+54.8%)
3. **大目标稳步提升**: car (+12.7%)、bus (+49.1%)
4. **最差类别改善**: bicycle 从 0.062 提升至 0.176，但仍是最低

### 7.2 改进效果归因分析

| 改进项 | 预期贡献 | 实际效果 |
|--------|---------|---------|
| 模型升级 (n→s) | 主要贡献 | 参数量增 3.5×，特征表达能力显著增强 |
| 输入增大 (640→800) | 重要贡献 | 小目标像素信息保留更多 |
| MixUp/CopyPaste | 辅助贡献 | 增加小目标样本多样性 |
| 随机擦除 | 辅助贡献 | 提升遮挡鲁棒性 |
| 更多训练轮数 | 辅助贡献 | 更充分收敛 |

### 7.3 各维度提升分析

**按目标尺寸**:
| 尺寸类别 | 代表类别 | 平均提升 |
|---------|---------|---------|
| 大目标 (>64px) | car, bus, truck | +35.8% |
| 中目标 (32-64px) | van, motor | +44.9% |
| 小目标 (<32px) | pedestrian, people, bicycle, tricycle | +96.7% |

**结论**: 小目标从改进中获益最大，验证了增大输入和增强策略的有效性。

### 7.4 局限性

1. **计算成本增加**: FLOPs 从 8.7G 增至 28.6G（3.3×），推理速度下降
2. **内存占用增加**: Batch 从 16 降至 8，训练时间增加
3. **稀有类别仍弱**: awning-tricycle (0.171) 和 bicycle (0.176) 仍是瓶颈
4. **过拟合风险**: 更多参数 + 更强增强需要平衡

## 9. 结论

通过模型升级、输入增大、数据增强三个维度的协同改进，mAP@0.5 从 29.79% 提升至 42.58%（+43.0%），验证了多维度优化策略的有效性。小目标类别提升最为显著（bicycle +183.9%），证明了增大输入分辨率和数据增强对小目标检测的关键作用。

**下一步**: 在不修改模型的前提下，探索推理策略优化（SAHI 切片推理）进一步提升精度。
