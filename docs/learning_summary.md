# 第一章 项目概述

## 1.1 研究背景

随着无人机技术的快速发展，低空无人机在物流配送、电力巡检、农业植保、安防监控等领域的应用日益增多。无人机航拍图像中的目标检测是实现自主飞行和智能分析的核心技术之一。然而，无人机航拍场景具有独特的挑战性：

1. **目标尺度极小**: 无人机飞行高度通常在 50~150 米，地面目标在图像中仅占 10~50 像素，远小于常规目标检测数据集中的目标尺寸（通常 > 100 像素）
2. **目标密集且遮挡严重**: 城市道路场景中，车辆和行人密集排列，相互遮挡
3. **类间差异小**: 例如自行车与摩托车、三轮车与篷三轮车在航拍视角下外观相似
4. **实时性要求高**: 无人机飞行速度快，需要低延迟的检测模型

## 1.2 研究目标

本项目的核心目标是：在 VisDrone2019-DET 数据集上，通过系统性的实验设计，逐步提升低空无人机小目标检测精度。

具体目标包括：
- 建立 VisDrone 数据集上的检测基准线（Baseline）
- 探索模型结构、输入分辨率、数据增强对小目标检测的影响
- 研究推理策略（SAHI 切片推理、TTA、阈值优化）的提升潜力
- 通过架构改进（P2 检测头 + CBAM 注意力）进一步提升性能
- 形成可复现、可扩展的完整实验流程

**核心挑战**:
1. 目标尺度极小: 无人机航拍目标通常 < 32px，远小于常规目标检测数据集
2. 目标密集且遮挡严重: 城市道路场景中，车辆和行人密集排列
3. 类间差异小: 例如自行车与摩托车、三轮车与篷三轮车在航拍视角下外观相似
4. 实时性要求高: 无人机飞行速度快，需要低延迟的检测模型

## 1.3 技术路线

本项目采用**五轮递进实验**的设计思路，每轮解决一个特定问题，逐步提升检测精度：

```
第一轮: 基线实验 → 建立评估基准，发现核心问题
   ↓
第二轮: 改进实验 → 模型升级 + 输入增大 + 数据增强
   ↓
第三轮: SAHI 推理 → 零训练成本的切片推理策略
   ↓
第四轮: 零训练优化 → 置信度阈值搜索 + TTA + 集成
   ↓
第五轮: 架构改进 → P2 小目标检测头 + CBAM 注意力
```

这种递进设计的核心价值在于：**每一步的改进都是可量化的，归因是清晰的**。我们不会说 "改了很多东西，效果变好了"，而是能精确地说 "从 YOLOv8n 升级到 YOLOv8s 带来了 X% 的提升，增大输入带来了 Y% 的提升"。

## 1.4 项目成果概览

## 3.2 数据预处理

### 3.2.1 格式转换详情

**转换脚本**: `src/prepare_data.py`

**转换逻辑**:
```python
def convert_visdrone_to_yolo(visdrone_line, img_width, img_height):
    parts = visdrone_line.strip().split(',')
    x, y, w, h = int(parts[0]), int(parts[1]), int(parts[2]), int(parts[3])
    score = int(parts[4])
    category = int(parts[5])

    # 过滤忽略区域和无效标注
    if category == 0 or score < 0:
        return None

    # 类别映射: VisDrone 1-10 → YOLO 0-9
    class_id = category - 1

    # 坐标归一化
    x_center = (x + w / 2) / img_width
    y_center = (y + h / 2) / img_height
    norm_w = w / img_width
    norm_h = h / img_height

    return f"{class_id} {x_center:.6f} {y_center:.6f} {norm_w:.6f} {norm_h:.6f}"
```

| 增强方法 | 原理 | 对小目标的作用 |

| MixUp | 两张图按比例混合 | 增加样本多样性 |
| CopyPaste | 复制粘贴目标到其他位置 | 直接增加小目标样本数 |
| 随机擦除 | 随机遮挡图像区域 | 模拟遮挡，提升鲁棒性 |
| HSV 增强 | 色调/饱和度/亮度抖动 | 颜色不变性 |
| 随机翻转 | 水平翻转 | 对称性不变性 |
| 随机缩放 | 图像缩放 | 尺度不变性 |
| 随机旋转 | 图像旋转 | 旋转不变性 |
| 随机平移 | 图像平移 | 位置不变性 |
| 随机剪切 | 图像剪切变换 | 透视不变性 |

# 第四章 YOLOv8 架构深度解析

## 4.1 目标检测基础概念

### 4.1.1 One-Stage vs Two-Stage

| 类型 | 代表 | 特点 |
|------|------|------|
| Two-Stage | Faster R-CNN | 先生成候选区域，再分类回归，精度高但速度慢 |
| One-Stage | YOLO, SSD | 直接预测类别和位置，速度快但精度略低 |

YOLO (You Only Look Once) 是典型的 One-Stage 检测器，一次前向传播完成所有检测。

### 4.1.2 Anchor-Based vs Anchor-Free

| 类型 | 代表 | 特点 |
|------|------|------|
| Anchor-Based | YOLOv5, Faster R-CNN | 预定义锚框，预测相对偏移 |
| Anchor-Free | YOLOv8, FCOS | 直接预测中心点和宽高 |

YOLOv8 采用 Anchor-Free 设计，无需预定义锚框，更简洁且泛化性更好。

### 4.1.3 评估指标

**IoU (Intersection over Union)**:
```
IoU = 交集面积 / 并集面积
```

**Precision 与 Recall**:
```
Precision = TP / (TP + FP)  # 检测出的目标中，正确的比例
Recall = TP / (TP + FN)     # 所有真实目标中，被检测出的比例
```

**AP (Average Precision)**:
```
AP = Precision-Recall 曲线下的面积
```

**mAP (mean Average Precision)**:
```
mAP = 所有类别 AP 的平均值
mAP@0.5 = IoU 阈值为 0.5 时的 mAP
mAP@0.5:0.95 = IoU 阈值从 0.5 到 0.95 (步长 0.05) 的平均 mAP
```

## 4.2 YOLOv8 整体架构

YOLOv8 由三个主要组件构成：

```
输入图像 (640×640×3)
    ↓
┌─────────────────────────────────┐
│  Backbone (特征提取)             │
│  CSPDarknet + C2f 模块           │
│  输出: P3(80×80), P4(40×40), P5(20×20) │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│  Neck (特征融合)                 │
│  PANet + FPN (双向特征金字塔)     │
│  融合多尺度特征                   │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│  Head (检测输出)                 │
│  Decoupled Head (解耦头)         │
│  Anchor-Free 直接预测            │
│  输出: 边界框 + 类别 + 置信度     │
└─────────────────────────────────┘
```

### 4.2.1 Backbone: CSPDarknet

Backbone 负责从输入图像中提取多尺度特征。YOLOv8 的 Backbone 基于 CSPDarknet，使用 C2f 模块替代了 YOLOv5 的 C3 模块。

**C2f 模块** (Cross Stage Partial with 2 convolutions):
```
输入 → Split → [分支1, 分支2] → N × Bottleneck → Concat → Conv → 输出
```

C2f 的优势：
- 梯度流更丰富，训练更稳定
- 参数量更少，计算更高效
- 跨阶段连接保留了更多特征信息

### 4.2.2 Neck: PANet + FPN

Neck 负责融合不同尺度的特征。YOLOv8 使用 PANet (Path Aggregation Network) + FPN (Feature Pyramid Network) 的双向结构：

```
P5 (20×20) ──→ 上采样 ──→ 与 P4 拼接 ──→ C2f ──→ P4 融合
P4 (40×40) ──→ 上采样 ──→ 与 P3 拼接 ──→ C2f ──→ P3 融合
P3 (80×80) ──→ 下采样 ──→ 与 P4 拼接 ──→ C2f ──→ P4 输出
P4 融合    ──→ 下采样 ──→ 与 P5 拼接 ──→ C2f ──→ P5 输出
```

**FPN (自顶向下)**: 高层语义信息流向低层，增强低层的语义理解
**PAN (自底向上)**: 低层位置信息流向高层，增强高层的定位能力

### 4.2.3 Head: Decoupled Head

YOLOv8 使用解耦检测头，将分类和回归分为两个独立分支：

```
特征图 → 共享卷积 → 分类分支 → 类别预测
                  → 回归分支 → 边界框预测
```

**解耦的优势**:
- 分类和回归任务的优化目标不同，解耦后可以独立优化
- 分类关注 "是什么"，回归关注 "在哪里"
- 避免两个任务互相干扰

### 4.2.4 损失函数

YOLOv8 使用三个损失函数的加权组合：

```
L_total = 7.5 × L_box + 0.5 × L_cls + 1.5 × L_dfl
```

**L_box (CIoU Loss)**:
```
CIoU = IoU - ρ²(b, b_gt) / c² - α × v

其中:
- ρ²: 中心点距离的平方
- c: 最小外接矩形的对角线长度
- α: 权重因子
- v: 宽高比一致性
```

**L_cls (BCE Loss)**:
```
L_cls = -[y × log(p) + (1-y) × log(1-p)]
```

**L_dfl (Distribution Focal Loss)**:
```
L_dfl = -((y_right - y) × log(S_left) + (y - y_left) × log(S_right))
```

DFL 将边界框坐标建模为离散概率分布，比直接回归坐标更精确。

## 4.3 YOLOv8 变体对比

# 第七章 实验三：SAHI 切片推理

## 7.1 实验目标

在不修改模型、不重新训练的前提下，通过 SAHI 切片推理策略提升小目标检测精度。

**核心问题**: 零训练成本的推理策略优化，能带来多少提升？

## 7.2 SAHI 技术原理

### 7.2.1 核心思想

SAHI (Slicing Aided Hyper Inference) 的核心思想是：将高分辨率大图切成重叠小块，分别送入检测模型推理，再将各切块的检测结果合并。

```
┌─────────────────┐     ┌───┬───┬───┐     ┌───────────┐
│  2000×1500 原图  │ ──→ │ 1 │ 2 │ 3 │ ──→ │ NMS 合并   │ ──→ 最终结果
│                 │     │ 4 │ 5 │ 6 │     │ 检测框去重  │
└─────────────────┘     └───┴───┴───┘     └───────────┘
                        切片 (重叠20%)
```

### 7.2.2 为什么 SAHI 有效？

**问题**: VisDrone 图片分辨率 ~2000×1500，直接缩放到 640×640 时：
- 15px 目标 → 6.4px（信息严重丢失）
- 30px 目标 → 12.8px（勉强可检测）

**SAHI 解决方案**: 将原图切成 640×640 小块时：
- 15px 目标 → 15px（保持原始分辨率）
- 30px 目标 → 30px（保持原始分辨率）
- 小目标在切块中像素占比大幅提高

### 7.2.3 切片参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 切片尺寸 | 640×640 | 匹配模型输入 |
| 重叠率 | 20% | 防止目标被切断 |
| 后处理 | NMS | 跨切块去重 |
| NMS 阈值 | 0.5 | IoU 阈值 |

## 7.3 实验配置

| 参数 | 值 |
|------|-----|
| 基础模型 | YOLOv8s Improved (best.pt) |
| 切片尺寸 | 640×640 |
| 重叠率 | 0.2 (20%) |
| 置信度阈值 | 0.25 |
| NMS 阈值 | 0.5 |

# 第八章 实验四：零训练优化

## 8.1 实验目标

在 SAHI 基础上，探索三种零训练成本的后处理优化策略。

**核心问题**: 不训练、不改模型，仅优化后处理策略，还能提升多少？

## 8.2 策略一：置信度阈值网格搜索

### 8.2.1 方法原理

置信度阈值控制检测框的过滤：阈值越高，保留的检测框越少；阈值越低，保留的检测框越多。

**关键洞察**: SAHI 切片推理后，小目标的置信度可能被分散到多个切块中。降低阈值可以保留更多真实检测。

### 8.2.2 网格搜索结果

| 置信度阈值 | mAP@0.5 | mAP@0.5:0.95 | 预测数 |
|-----------|---------|--------------|--------|
| **0.05** | **0.4903** | **0.2677** | 81,344 |
| 0.10 | 0.4826 | 0.2649 | 63,271 |
| 0.15 | 0.4733 | 0.2618 | 53,716 |
| 0.20 | 0.4635 | 0.2581 | 46,964 |
| 0.25 | 0.4523 | 0.2539 | 41,888 |
| 0.30 | 0.4389 | 0.2487 | 37,733 |
| 0.35 | 0.4226 | 0.2414 | 34,024 |
| 0.40 | 0.4021 | 0.2332 | 30,810 |

### 8.2.3 为什么低阈值更好？

1. **SAHI 的特殊性**: 切片推理导致同一目标在多个切块中被检测，置信度被分散
2. **低阈值保留更多检测**: COCOeval 的 AP 计算不依赖置信度排序，而是按 IoU 匹配
3. **小目标的置信度天然较低**: 降低阈值可以保留更多小目标检测

## 8.3 策略二：SAHI + TTA

### 8.3.1 方法原理

TTA (Test Time Augmentation) 在推理时对输入进行增强，将增强后的结果与原图结果合并。

### 8.3.2 评估结果

| 指标 | SAHI | SAHI+TTA | 提升 |
|------|------|----------|------|
| mAP@0.5 | 0.4523 | **0.4710** | **+4.1%** |
| mAP@0.5:0.95 | 0.2539 | **0.2636** | **+3.8%** |

推理耗时: 789s (1.44s/张)，约为普通 SAHI 的 5.6 倍。

## 8.4 策略三：多模型集成

### 8.4.1 评估结果

| 指标 | Ensemble | vs Improved |
|------|----------|------------|
| mAP@0.5 | 0.3535 | -17.0% |
| mAP@0.5:0.95 | 0.2140 | -12.8% |

### 8.4.2 失败原因

集成效果不佳（0.3535 < 0.4258）的原因：
1. YOLOv8n 基线模型质量过低（mAP=0.2979）
2. 给基线模型 0.7 权重过高
3. 两个模型架构相似，缺乏多样性

## 8.5 综合对比

| 排名 | 方法 | mAP@0.5 | vs 基线 |
|------|------|---------|---------|
| 1 | **SAHI(conf=0.05)** | **0.4903** | **+64.6%** |
| 2 | SAHI+TTA | 0.4710 | +58.1% |
| 3 | SAHI(conf=0.25) | 0.4523 | +51.8% |
| 4 | Improved | 0.4258 | +43.0% |
| 5 | Ensemble | 0.3535 | +18.7% |

# 第九章 实验五：P2 检测头 + CBAM 注意力

## 9.1 实验目标

在标准 YOLOv8s 基础上，通过架构层面的改进进一步提升小目标检测能力。

**核心问题**: 从模型架构层面改进，能带来多少额外提升？

## 9.2 P2 小目标检测头

### 9.2.1 设计原理

标准 YOLOv8 有三个检测头：P3 (80×80)、P4 (40×40)、P5 (20×20)。其中 P3 是最小的特征图，但仍然无法有效检测 <16px 的小目标。

**P2 检测头**: 增加 160×160 特征图的检测层，专门检测 <16px 小目标。

```
P5 (20×20): 检测 >64px 大目标
P4 (40×40): 检测 32-64px 中目标
P3 (80×80): 检测 16-32px 小目标
P2 (160×160): 检测 <16px 微小目标 ← 新增
```

### 9.2.2 检测点数

| 检测层 | 特征图尺寸 | 检测点数 | 覆盖目标尺寸 |
|--------|-----------|---------|-------------|
| P2 | 160×160 | 25,600 | <16px |
| P3 | 80×80 | 6,400 | 16-32px |
| P4 | 40×40 | 1,600 | 32-64px |
| P5 | 20×20 | 400 | >64px |
| **总计** | - | **34,000** | - |

标准 YOLOv8 只有 8,400 个检测点，P2 版本增加到 34,000 个（+305%）。

## 9.3 CBAM 注意力机制

### 9.3.1 设计原理

CBAM (Convolutional Block Attention Module) 由两个子模块组成：

1. **通道注意力 (Channel Attention)**: 学习各通道的重要性权重
2. **空间注意力 (Spatial Attention)**: 学习各空间位置的重要性权重

```
输入 → 通道注意力 → 空间注意力 → 输出
```

### 9.3.2 为什么对小目标有效？

小目标在特征图中信号弱，容易被背景噪声淹没。CBAM 的空间注意力可以让模型聚焦于小目标所在区域，抑制背景噪声。

### 9.3.3 插入位置

在 Backbone 的 P2/P3/P4 层后插入 CBAM：

```
Layer 2 (P2 特征) → CBAM → Layer 4
Layer 5 (P3 特征) → CBAM → Layer 7
Layer 8 (P4 特征) → CBAM → Layer 10
```

# 第十章 五轮实验综合分析

## 10.1 实验结果总览

| 轮次 | 方法 | mAP@0.5 | mAP@0.5:0.95 | 累计提升 | 训练成本 | 推理成本 |
|------|------|---------|--------------|---------|---------|---------|
| 1 | YOLOv8n Baseline | 0.2979 | 0.1663 | - | ~65min | 0.03s |
| 2 | YOLOv8s Improved | 0.4258 | 0.2453 | +43.0% | ~2.5h | 0.05s |
| 3 | SAHI (conf=0.25) | 0.4523 | 0.2539 | +51.8% | 零 | 0.24s |
| 4 | SAHI (conf=0.05) | 0.4903 | 0.2677 | +64.6% | 零 | 0.24s |
| 5 | P2+CBAM (1ep) | 0.0234 | 0.0085 | -92.1% | ~48h | - |

## 10.2 递进实验的价值

### 10.2.1 归因清晰

每轮实验只改变一个维度，改进效果可精确归因：

- 第二轮: 模型升级 + 输入增大 + 数据增强 → +43.0%
- 第三轮: SAHI 切片推理 → +8.8% (从 42.58 到 45.23)
- 第四轮: 置信度阈值优化 → +8.4% (从 45.23 到 49.03)

### 10.2.2 优化维度互补

```
数据层: 数据增强 (MixUp, CopyPaste, Erasing)
模型层: 模型升级 (YOLOv8n → YOLOv8s)
输入层: 输入增大 (640 → 800)
推理层: SAHI 切片推理
后处理层: 置信度阈值优化 + TTA
```

每个维度独立优化，可以叠加使用。

## 10.3 关键发现

### 10.3.1 小目标检测的系统性优化

小目标检测不是一个单一问题，而是需要多维度的系统性优化：

| 优化维度 | 方法 | 效果 |
|---------|------|------|
| 数据 | CopyPaste 增加小目标样本 | 中 |
| 模型 | 更大的模型容量 | 高 |
| 输入 | 更大的输入分辨率 | 中 |
| 推理 | SAHI 切片推理 | 高 |
| 后处理 | 低置信度阈值 | 中 |

### 10.3.2 零训练优化的价值

在不修改模型的前提下，仅优化推理策略即可获得 64.6% 的累计提升。这说明推理策略是被严重低估的优化维度。

### 10.3.3 集成学习的局限

多模型集成在基线模型质量不足时效果不佳。集成的前提是每个模型都有一定质量。

# 第十一章 认知升华与反思

## 11.1 对目标检测的理解

### 11.1.1 检测的本质

目标检测的本质是 "在正确的位置找到正确的物体"，包含三个子问题：

1. **定位**: 预测边界框坐标 → L_box, L_dfl
2. **分类**: 预测类别 → L_cls
3. **置信度**: 排序预测，决定阈值

这三个问题互相耦合，任何一个出错都会影响最终结果。

### 11.1.2 mAP 的局限性

mAP 是一个综合指标，可能掩盖具体问题：

- mAP@0.5 = 0.4258 听起来还行
- 但 bicycle 的 AP 只有 0.176，awning-tricycle 只有 0.171
- car 的 AP 是 0.815，拉高了均值

**教训**: 评估应该看每个类别，而不只是整体 mAP。

### 11.1.3 小目标检测的本质困难

小目标检测是一个信息瓶颈问题：

```
原始信息: 15×30 像素的行人 = 450 个像素
缩放到 640: 5×10 像素 = 50 个像素
经过 5 次下采样: 在 P5 上不存在
```

即使模型再强大，如果输入信息本身就不够，检测也不可能好。

## 11.2 实验设计的认知

### 11.2.1 递进实验的价值

递进实验让每个改进的贡献可量化，避免了 "改了很多东西，效果变好了，但不知道哪个有用" 的问题。

### 11.2.2 系统思维的重要性

检测系统不仅仅是模型，而是数据→模型→推理→评估的全链路。每个环节都影响最终效果。

### 11.2.3 踩坑是最好的学习

每个 bug 的解决都加深了对系统的理解：
- PIL.Image.open 被 pi_heif 篡改 → 第三方库副作用
- 临时文件被 glob 误读 → 健壮性问题
- COCOeval 忘记调用 summarize() → API 理解不完整

## 11.3 工程实践的认知

### 11.3.1 环境配置的重要性

环境配置是项目的基础，任何配置问题都可能导致训练失败或结果不正确。

### 11.3.2 版本控制的价值

Git 版本控制让实验可追溯、可回滚、可协作。每个实验都应该有独立的 commit。

### 11.3.3 文档的重要性

好的文档让实验可复现、可理解、可传承。文档应该包括：实验目的、配置、结果、分析、结论。
