# 钢珠检测训练配置

> 钢珠检测（含直径测量）的训练配置，遵循 YOLO 应用典型闭环（docs/tutorial/07）。

## 数据

- **来源**：HuggingFace `daffae/steelball_detect`（2026-07 采集，竞赛场景）
- **规模**：1943 张（train 1555 + val 388），单类 `steel_ball`
- **清洗**：json→yolo 转换 + 去重 + 过滤无效框
- **特点**：含强反光、每图 1-10 球（20-30px 小目标）

## 训练配置

| 参数 | 值 | 理由 |
|---|---|---|
| 模型 | yolo26n（或 yolo11n）| 单类，小模型够用 + 快 |
| imgsz | 640 | 钢珠 20-30px，平衡精度/速度 |
| epochs | 100 | 数据足，充分训练 |
| batch | 16 | 单类数据小，显存够 |
| mosaic | 1.0 | 多尺度增强 |
| copy_paste | 0.3 | 密集小目标增强 |
| degrees | 90 | 钢珠方向任意 |
| hsv | 0.015/0.7/0.4 | 反光/光照鲁棒 |
| patience | 30 | 早停 |

## 运行

```bash
python scripts/train_steelball.py --model yolo26n.pt --imgsz 640 --epochs 100
```

## 评估指标

| 指标 | 关注点 |
|---|---|
| mAP@0.5 | 检测效果 |
| **定位精度** | 球心坐标误差（控制/测量关键）|

**关键**：钢珠检测重点是**定位精度**（球心坐标 + 尺寸），不是分类。

## 直径测量（进阶功能）

检测 bbox → 像素直径 → 标定 → 物理直径：

```
方法1（直接）：像素直径 ≈ bbox 宽/高（钢珠近似圆形）
方法2（圆拟合）：bbox 内像素 HoughCircles / 最小二乘圆拟合

像素→物理：已知真实直径 D_real，标定系数 k = D_real / D_pixel
  · 固定相机 → 标定一次
  · 移动相机 → 用参照物实时换算
```
