# 钢珠检测（YOLO 应用独立分支）

> 钢珠检测 + 直径测量 + 反光特征校验。
> 作为 YOLO 应用的独立分支，遵循应用流程闭环（数据→训练→评估→部署）。

## 定位

- **独立应用**：与 VisDrone 平级，展示 YOLO 检测的另一类场景
- **技术重点**：小目标检测 + 测量（直径）+ 反光特征利用
- **通用框架**：遵循应用流程闭环（数据→训练→评估→部署）

## 闭环流程

```
数据准备 → 训练微调 → 评估 → 部署 + 测量
```

## 一、数据准备

- **来源**：HuggingFace `daffae/steelball_detect`（2026-07 采集，电赛场景）
- **规模**：1943 张（train 1555 + val 388），单类 `steel_ball`
- **清洗**：LabelMe json → YOLO txt 转换（`scripts/convert_steelball_json.py`）
  - 去重 / 过滤无效框 / 优先 txt 标注
  - 数据从 430 张扩展到 1943 张（4.5 倍）
- **EDA**（`scripts/steelball_eda.py`）：
  - 每图均值 5.7 球（1-10），多目标场景
  - 钢珠 25×32px（小目标）
  - **高光占比 0.15（反光是普遍特征）**

## 二、训练配置

| 参数 | 值 |
|---|---|
| 模型 | yolo26n（单类小模型）|
| imgsz | 640 |
| epochs | 100 |
| 增强 | mosaic + copy_paste + degrees=90 |

详见 [docs/training_config.md](docs/training_config.md)。

## 三、检测 + 测量（scripts/steelball_measure.py）

```
YOLO 检测 → bbox → 像素直径 → 标定 → 物理直径
```

- **直径测量**：像素直径 ≈ bbox 平均边（钢珠近似圆形）
- **标定**：提供真实直径，自动算 cm/px 系数
- **反光校验**（钢珠特定 trick，可开关）：
  - 钢珠是金属球，高光点是稳定特征
  - bbox 内找高光点，质心近中心 → 确认钢珠（排除误检）
  - **注意**：这是处理手段，不是通用框架
