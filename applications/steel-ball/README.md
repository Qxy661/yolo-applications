# 钢珠检测（电赛 H题 视觉部分）

> 电赛 H题「车载平衡滚球」的 YOLO 钢珠视觉识别——练手/学习项目。
> 复用主项目的 YOLO 检测能力，聚焦**钢珠检测**（不强调全流程控制）。

## 目标

- 用 YOLO 检测管道中的钢珠位置（输出坐标）
- 解决钢珠**反光**这一最大难点
- 为电赛 H题 的"2秒定位"提供视觉基础

## 路线

```
数据（钢珠图片采集/数据集）→ 训练 YOLO → 评估 → 部署(K230/PC)
```

## 关键技术点

| 项 | 方案 |
|---|---|
| 模型 | YOLO（小模型，实时）|
| 检测目标 | 管道内钢珠（反光/光照变化）|
| 输出 | 钢珠坐标（供控制用）|
| 实时性 | ≥30fps |

## 与主项目的关系

- 复用主项目的 YOLO 检测流程（train/val/eval）
- 数据换成钢珠数据集
- 是 M2 检测能力的应用延伸
