### 第 2 页 — 风电叶片检测：为什么重要？为什么难？

**排版**: 上方行业背景 + 下方五大挑战

**插图**:
- **左上**: `images/fig02_wind_farm.png` — 风电场全景 + 叶片缺陷示例
- **下方**: `images/fig03_challenges.png` — 五大技术挑战卡片

```
行业背景:
• 全球风电装机 >1000GW，叶片维修成本占总维护 15-20%
• 传统人工检测: 单台 2-4 小时，高空作业风险大，漏检率 15-30%
• AI 自动检测: 无人机巡检 15-30 分钟，mAP >90%

五大技术挑战:

| 挑战 | 具体问题 | 严重度 |
|------|---------|--------|
| ① 尺度差异极大 | 微小裂纹 2-5px vs 大面积侵蚀数百px | ★★★★★ |
| ② 背景高度复杂 | 天空/云层/塔架干扰，缺陷对比度低 | ★★★★ |
| ③ 部署环境受限 | 无人机载荷有限，模型需<10MB | ★★★★ |
| ④ 标注数据稀缺 | 专业标注成本高，样本不平衡 | ★★★ |
| ⑤ 缺陷形态多样 | 裂纹(线)/侵蚀(面)/孔洞(点)/雷击(放射) | ★★★ |

典型缺陷类型:
| 缺陷 | 视觉特征 | 检测难度 | 占比 |
|------|---------|---------|------|
| 裂纹 | 细长线状，宽<5px | 极高 | 35% |
| 侵蚀 | 面状剥落，边界不规则 | 中等 | 25% |
| 雷击 | 焦黑放射状 | 中等 | 8% |
| 涂层脱落 | 片状剥落 | 中等 | 12% |
| 孔洞 | 圆形/不规则空洞 | 中等 | 10% |
```

## 第二部分：文献调研 — 3 篇论文精讲 (第 3-5 页)

### 第 3 页 — 论文一：GCB-YOLO (2025) — 轻量化+CA+BiFPN

**排版**: 左侧论文信息 + 右侧架构图

**插图**:
- **右侧**: `images/fig04_gcb_yolo.png` — GCB-YOLO 架构图
  - GhostNet Backbone(绿) → CA注意力(橙) → BiFPN Neck(蓝) → Head

```
论文: GCB-YOLO, Wind Energy 2025 (DOI: 10.1002/we.70029)

三大创新:

① GhostNet 轻量化 Backbone
   一半正常卷积 + 一半廉价线性变换
   → 参数量减少 ~50%

② CA 坐标注意力
   X方向1D池化 + Y方向1D池化 → 保留行列坐标
   → 对小目标友好，不抑制空间位置

③ BiFPN 加权特征融合
   双向融合 + 可学习权重
   → 比单路径FPN保留更多多尺度信息

结果: 7.5MB | 94.72% mAP | 115.3 FPS
启示: GhostNet+CA+BiFPN = 超轻量+高精度
```

```
论文: WTBD-YOLOv8, Sustainability 2024 (DOI: 10.3390/su16114467)

四大创新:

① GhostCBS — 替换标准卷积，参数-38.2%
② DFSB-C3k2 — 密集特征尺度平衡

|------|------------|------|------|
| AP@0.5 | 98.3% | 96.1% | +2.2pp |
| 小目标AP | 97.9% | 93.1% | +4.8pp |
| 参数量 | 1.99M | 3.22M | -38.2% |

启示: "更少参数+更高精度"的罕见组合
```

### 第 5 页 — 论文三：LE-YOLO (2024) — 零参数注意力+高效损失

**排版**: 左侧创新点 + 右侧SimAM原理

**插图**:
- **右侧**: `images/fig06_le_yolo.png` — SimAM 零参数注意力原理

```
论文: LE-YOLO, IEEE Access 2024 (DOI: 10.1109/access.2024.3463391)

三大创新:

① GSConv — Ghost+Shuffle，参数-44%，计算-42%

② SimAM 零参数注意力
   e_t = (2t - μ)² / (2σ² + ε)
   → 零参数! 零开销! 免费添加
   → 效果: +2.8% mAP

③ EIoU 损失函数
   分解为: 重叠面积 + 中心距离 + 宽高差异
   → 比CIoU梯度更精确，收敛更快

结果: 2.1M参数 | 78.7% mAP | 105.1 FPS
启示: SimAM零参数可免费添加，EIoU直接替代CIoU
```

### 第 9 页 — 损失函数演进

**排版**: 演进时间线 + 推荐方案

**插图**:
- **居中**: `images/fig09_loss.png` — 损失函数演进

```
损失函数演进:

MSE → IoU → GIoU → DIoU → CIoU → EIoU → DFL
 (无法反映重叠)  (不相交梯度为零)  (引入包围框)  (加中心距离)  (加宽高比)  (分解三组件)  (离散分布)

每步改进动机:
• GIoU: 不相交也有梯度
• DIoU: 直接最小化中心距离
• CIoU: 三重优化(重叠+距离+形状)
• EIoU: 分解宽高，梯度更精确
• DFL: 坐标建模为分布，小目标更鲁棒

风电推荐: EIoU + DFL
• EIoU: 细长裂纹的宽高比梯度更稳定
• DFL: 5px裂纹偏移2px=40%误差，分布建模更鲁棒
```
