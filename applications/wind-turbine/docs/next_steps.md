## 下一步方向（按优先级排列）

### P0：确认当前最佳方案

**问题**：YOLOv8n mAP 82.80% 是当前最好结果，但这个结果是基于 2 类训练还是 5 类？检查 `runs/detect/compare_yolov8n/` 的训练配置，确认它用的数据配置和超参数。如果训练还没跑完，补跑一次完整的 **YOLOv8n + COCO 预训练 + 全参数微调** 作为新基线。

**命令**：

```bash
python src/train.py --model yolov8n.pt --epochs 150 --batch 8 --imgsz 640
```

### P1：做一次有效的架构改进

**核心问题**：之前的 YAML→Train 全部失败（mAP 0.43-0.57），主因是随机初始化。

**正确方法**：加载 baseline best.pt → 修改模型结构 → 低学习率微调（不是从 YAML 创建新模型然后随机初始化）

具体方案：

```python
# 伪代码：有效改进路径
model = YOLO("weights/yolov8n.pt")  # 加载已训练好的模型
# 在代码中修改 model.model 结构（加注意力/改head）
# model.train(..., lr0=0.0001)  # 低学习率微调
```

尝试方向（三选一，不要全做）：
1. **加 SE/ECA 注意力** — 最简单，计算量最低，适合小数据集
2. **增大输入到 800px** — VisDrone 经验表明增大输入有效
3. **SAHI 切片推理** — 零成本，直接套用 VisDrone 的 `sahi_eval.py`

### P2：完善 5 类数据集

**问题**：peeling（0 样本）和 hole（0 样本）完全缺失，lightning 仅 92 样本（5.2%）

**方案**：
1. 搜索更多开源风电缺陷数据集（补充 lightning/peeling/hole）
2. 用 SAM 对现有图片做辅助标注
3. 数据增强（旋转/裁剪/色彩抖动）扩展现有样本
4. 如果 5 类数据实在凑不齐，承认 2 类方案，把 crack+erosion 做到极致

### P3：SAM 分割完整评估

代码已就绪（`src/sam/run_yolo_sam.py`），需要：
1. 在完整 val 集上跑 YOLO→SAM 流水线
2. 计算分割 mIoU、Dice 系数
3. 可视化分割质量（边界清晰度、过分割/欠分割）
4. 决定是否需要微调 SAM

### P4：消融实验补完

当前消融实验只做了**冻结策略**的消融。还需补充：
1. **数据增强消融**：Mosaic/MixUp/CopyPaste 各贡献多少
2. **输入尺寸消融**：640 vs 800 vs 1280
3. **预训练权重消融**：COCO vs ImageNet vs 无预训练

### P5：部署与工程化

1. **ONNX 导出** → TensorRT 加速推理
2. **SAHI 切片推理** → 解决大图小缺陷问题
3. **推理速度基准**：单卡 RTX 4060 上测 FPS

## 关键教训（不要重复踩坑）

1. **⚠️ 不要从 YAML 随机初始化训练** — 小数据集必须用 COCO 预训练，YAML→Train 路线已确认失败
2. **⚠️ 不要在小数据集上冻结** — 冻结任何层都降精度，全参数微调最优
3. **⚠️ 不要一次性做太多改进** — 从最简单的 SE 注意力开始，一次只加一个改动
4. **✅ YOLOv8n > YOLOv11n** — 在当前 1K 数据规模下，老模型反而好
